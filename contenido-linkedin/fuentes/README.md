# Fuentes de inspiración — material bruto, no documentación

Esta carpeta es **material de trabajo, no decisiones documentadas** — no forma parte del canvas ni de los módulos. Se alimenta automáticamente todos los días con novedades de IA/datos (blogs especializados, foros, X, actualidad, en español e inglés), traducidas a lenguaje llano, pensadas como semillas para el plan de contenido de `contenido-linkedin/estrategia-contenido.md` y `contenido-linkedin/calendario.md`.

Un archivo por mes (`2026-07.md`, `2026-08.md`...), con una sección por día. Cuando algo de aquí se convierte en un post real, se referencia desde `contenido-linkedin/calendario.md` — esta carpeta no se borra ni se "limpia", es el archivo bruto histórico.
