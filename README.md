# Consultoría2 — Workspace de posicionamiento

Este repo es el sistema de trabajo entre **Alberto Mariscal** y **Claude (actuando como "Raúl", su consultor de posicionamiento 1:1)** para lanzar su consultoría de datos y automatización para pymes.

No es software. Es la sustitución casera del "workspace privado en Notion + soporte 1:1" que ofrecía un programa de posicionamiento de pago que Alberto decidió no contratar — usamos la misma lógica de fases, documentada y adaptada en `00-metodologia/`, y la ejecutamos nosotros mismos, sesión a sesión, por escrito.

## Cómo navegar el repo

| Carpeta | Qué contiene |
|---|---|
| `00-metodologia/` | El protocolo de 6 módulos que estamos siguiendo |
| `01-diagnostico/` | Módulo 1 (Problema) y Módulo 2 (Solución) |
| `02-sistema/` | Módulo 3 (Oferta), 4 (Mensaje), 5 (Audiencia) |
| `03-gtm/` | Módulo 6 (Canal, funnel, plan de contenido) |
| `canvas/` | El Positioning Canvas — el resumen de una página, vivo |
| `materia-prima/` | Evidencia real (logros, cifras, casos) sacada del CV/wiki de Alberto |
| `contenido-linkedin/` | Estrategia, calendario y borradores de posts de LinkedIn |
| `seguimiento/` | Registro de sesiones y métricas de LinkedIn |
